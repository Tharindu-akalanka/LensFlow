# SnapSort 0.3.0-rc.2

Windows desktop release candidate. First published source snapshot of the accumulated SnapSort implementation in the existing LensFlow repository.

## Included

- Local import, preparation, grouping and quality-assisted culling.
- Guided review, multi-selection, rejection reasons and Space preview.
- Offline face, visual and aesthetic model integration.
- Close-choice comparison; persistent group corrections and independent undo.
- XMP and Lightroom Classic plug-in/transfer workflow.
- Maintainer documentation, development journey and regression checks.

## Latest changes

Combine selected photos, move to another group, merge, separate or split. Undo affects grouping only. Equal-quality candidates use stable ordering; Close choices presents strong alternatives.

## Windows portable build

If attached to the release, close older instances before running the binary. Runtime/model dependencies are bundled. Source-build instructions are in the root README.
