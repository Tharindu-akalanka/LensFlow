# Project history

The repository began as LensFlow, a planned cloud studio-management product. Its NestJS/PostgreSQL starter, login/dashboard pages and process templates did not become shipped SnapSort features. SnapSort is the active local photo-culling product.

The 2026-11-06 repository cleanup removed those obsolete tracked scaffolds, the Docker configuration and their inactive CI/release workflows from the current tree. No commit history or published version tag was rewritten. Ignored local data, credentials, dependencies and build outputs were left untouched.

The earlier material is still available at [the pre-cleanup main snapshot](https://github.com/Tharindu-akalanka/LensFlow/tree/49d4f1aedf461eb6c2b3154a3f9f86c47865b92f). It is historical context, not documentation of active product capabilities.

For the active product, start with the [README](../README.md), [case study](CASE_STUDY.md), [desktop user guide](USER_GUIDE.md) and [browser demo scope](../web-demo/README.md). Historical validation notes are kept because they record evidence and limitations for their particular versions.
