# Version & Release Strategy

## Versioning Scheme (Semantic Versioning)
We follow Semantic Versioning (`MAJOR.MINOR.PATCH`):
- **MAJOR**: Breaking API changes, massive UI overhauls.
- **MINOR**: New features (backward-compatible).
- **PATCH**: Bug fixes, minor improvements.

## Planned Releases

### v1.0.0 (MVP)
- Features: Auth, Client Management, Booking, Shoot tracking, Local File Storage, Invoicing.
- Target: Core workflow establishment for single studios.

### v1.1.0 (Enhancements)
- Features: S3 integration, Email Notifications, Google Calendar Sync.

### v1.2.0 (Optimization)
- Features: Performance tuning, advanced analytics dashboard.

### v2.0.0 (Major Upgrade)
- Features: AI photo culling, multi-branch studio support.
