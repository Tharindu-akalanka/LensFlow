# SnapSort 0.3.0-rc.3

Windows release candidate with group-first target selection and simpler shortlist controls.

- Choose **Suggest for me**, enter the count and update the shortlist.
- Select group winners before repeated frames within the same quality tier.
- Explain extra similar frames, quality-review candidates and unavailable target counts.
- Consider the weakest detected face when ranking group-photo focus.
- Show human review progress, Rejected/Unreviewed collections and next-unreviewed navigation.

Original bytes and saved user decisions remain unchanged. Body-pose/emotion ranking is not included. Real-shoot grouping accuracy, real Adobe catalog execution, large-shoot/platform qualification and distribution signing remain open.

See [selection policy and validation](../GROUP_FIRST_TARGETS.md) and [review-progress behavior](../REVIEW_PROGRESS_UPDATE.md).

Local checks: 70 Python tests, frontend lint/build, real-engine desktop workflow and standalone engine integration. The GitHub release page records the downloadable executable's byte size and SHA-256 checksum. The binary is unsigned.
