# SnapSort generated branding

Generated using the built-in ImageGen tool (not the API/CLI fallback). These assets were generated under the working name LensFlow and contain no lettering; the same imagery is now used for the selected name SnapSort. The actual original generation prompts are preserved below. Source images are kept unchanged; smaller UI versions and Windows ICO sizes are export derivatives.

## Saved assets

- `snapsort-app-icon.png`: original generated aperture mark, now used for SnapSort.
- `app-icon-128.png`: titlebar and desktop window icon.
- `favicon.png`: browser development preview icon.
- `empty-project.png`: original generated camera/contact-sheet illustration.
- `empty-project.webp`: smaller transparent empty-project UI image.
- `../../../desktop/build/icon.ico`: Windows executable/portable icon.

Toolbar and navigation icons use the existing Lucide React vector set for consistent readability.

## Final generation prompts

### lensflow_logo

Use case: logo-brand. Asset type: production Windows desktop app icon and titlebar logo for LensFlow, a fully local photo culling application. Design one premium square app icon: a clean simple six-blade camera aperture inside a circular lens, centered on a graphite rounded-square tile with a very subtle soft bevel, reminiscent of the material polish of iOS icons. Matte charcoal and restrained desaturated ice-blue/silver aperture blades. High contrast silhouette, readable at 24 pixels, generous internal padding, no small decorative details. The tile fills nearly the full square canvas, with dark charcoal behind its rounded corners, no white border. No letters, no text, no watermark, no unrelated objects. Icon only, front-facing, soft studio light, minimal and refined. Not a mockup or a UI screenshot.

### lensflow_empty

Use case: stylized-concept. Asset type: small empty-project illustration for LensFlow desktop photo culling software. One compact tasteful 3D still life: a graphite mirrorless camera with a softly reflective lens in front of two slightly offset rounded photographic contact-sheet cards, each with small abstract mountain landscape thumbnails. Polished soft iOS-like material rendering and rounded edges, neutral charcoal and silver grey with a little muted ice-blue. A calm professional photographic tool illustration, front three-quarter view, neatly centered, generous empty margins. Soft diffuse studio illumination, very restrained shadow. No text, no brands, no logos, no watermark, no people, no interface screenshot. Genuine transparent background around the objects; preserve alpha.
